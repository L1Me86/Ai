## Что исключено

Не загружались автоматически создаваемые каталоги и файлы сборки/кэша: `.dart_tool`, `build`, `bin`, `obj`, `Debug`, `Release`, `x64`, временные логи и аналогичные производные артефакты. Они не нужны для чтения материалов и обычно восстанавливаются при сборке проекта.
